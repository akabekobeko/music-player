# 多言語対応

英語を既定とし、日本語へ切り替えられるようにします。

## ルーティング

Astro 組み込みの i18n ルーティングを使います。

```ts
// astro.config.ts
i18n: {
  defaultLocale: "en",
  locales: ["en", "ja"],
  routing: { prefixDefaultLocale: false },
}
```

| ページ | 英語 | 日本語 |
| --- | --- | --- |
| トップ | `/parade/` | `/parade/ja/` |
| ダウンロード | `/parade/download/` | `/parade/ja/download/` |
| 404 | `/parade/404.html` (英語のみ。GitHub Pages は 1 つの 404 ページしか使えない) | |

- 英語にはプレフィックスを付けない。既定の言語の URL を短く保ち、既存のリンク (README など) を `/ja/` の有無に関わらず安定させるため
- `src/pages/ja/` 配下のページは、英語側の `.astro` を再利用する。ページの本体は `src/components/` のコンポーネントにし、`index.astro` と `ja/index.astro` は locale を渡すだけの薄いファイルにする (アプリの `route.tsx` + `PageContent.tsx` と同じ発想)
- `<html lang>` は locale に合わせる
- `<head>` に `hreflang` の alternate (`en`、`ja`、`x-default` は英語) を出す。`@astrojs/sitemap` の `i18n` 設定で `sitemap.xml` にも出す

## 辞書

アプリの `src/shared/locales` と同じフラットな辞書にします。

```
web/src/i18n/
├── en.ts        # { "nav.download": "Download", ... }
├── ja.ts
├── t.ts         # t(locale, key, params)
└── types.ts     # Locale, keys
```

- キーは `en.ts` を正とし、`ja.ts` はその `Record<keyof typeof en, string>` で型付けする。訳漏れを型で検出する
- 文章が長い機能説明もすべて辞書に置く。`.astro` にハードコードした英文を残さない
- 日付 (リリース日) は `Intl.DateTimeFormat(locale, { dateStyle: "long" })` で locale ごとに整形する
- サイズは locale に関わらず `123.4 MB` の形式

## 言語の切り替え

- ヘッダーに言語切り替えを置き、全ページ・全画面幅で常時表示する ([ページ構成](../features/pages.md))。表示は現在と反対の言語名 (英語ページでは「日本語」、日本語ページでは「English」) にし、対応するページの URL へリンクする。言語名はその言語で表記し、翻訳しない。「Switch to Japanese」/「英語に切り替え」の補足は視覚的に隠したテキスト (`sr-only`) で添える (`aria-label` にすると表示ラベルとアクセシブル名が食い違い、Lighthouse の label-content-name-mismatch になる)
- 幅が足りないモバイルでは「JA」/「EN」に短縮してよいが、非表示にはしない
- リンクは `<a>` で、JavaScript なしで動く。Astro の `getRelativeLocaleUrl` で同じページの他言語 URL を組み立てる
- 訪問者の言語による自動リダイレクトはしない ([スコープ](../scope.md))。Phase 4 で、`navigator.language` が `ja` で始まり、まだ日本語版を見ていない訪問者に対してだけ、トップ ページに案内バナーを出す案を任意とする。バナーを閉じた状態は `localStorage` に保存する

## スクリーンショット

スクリーンショットはアプリの言語を英語にして撮影し、英語 / 日本語の両ページで共有します ([スクリーンショット](../features/screenshots.md))。日本語 UI のスクリーンショットは撮りません。代わりに、アプリが英語と日本語に対応していることをサイトの文章で明記します。

- トップ ページの機能紹介に、設定ページ (テーマと言語の設定) のスクリーンショットと「英語と日本語の UI を切り替えられる」説明を置く ([トップ ページ](../features/top-page.md))
- ヒーローの補足にも対応言語を一言添える

`alt` は辞書から locale ごとに与えます。

## 文体

- 英語: アプリの `en.ts` と同じく簡潔な文。製品名は `Parade`
- 日本語: アプリの `ja.ts` と仕様書に合わせ、です・ます調。英数字と日本語の間に半角スペースを置く。技術用語は英語表記のまま
