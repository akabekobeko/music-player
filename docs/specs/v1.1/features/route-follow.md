# ルートの追従

[ライブラリーへの即時反映](library-refresh.md) の一部です。編集で表示アーティストやアルバムキーが変わったとき、開いている画面を追従させる規則です。

## 規則

判定には `UpdateMusicsSummary.updated[].displayArtist` / `albumKey` ([IPC 型定義](../architecture/ipc-types.md)) を使います。

### Artist ビュー (`/artists/name/:artistName`)

| 状況 | 動作 |
| --- | --- |
| 対象曲の元の表示アーティストが表示中でない | 何もしない |
| 更新後の表示アーティストが 1 種類 | その名前へ `navigate(..., { replace: true })` |
| 更新後の表示アーティストが複数 | 元のアーティストに曲が残っていればそのまま、残っていなければ `/artists` へ戻る |

### Album ビュー

| 状況 | 動作 |
| --- | --- |
| 下段ペインの選択アルバムが対象でない | 何もしない |
| 更新後のアルバムキーが 1 種類 | 選択キーを新しいキーに差し替える |
| 更新後のアルバムキーが複数 | 元のキーが一覧に残っていればそのまま、消えていれば下段ペインを閉じる (v1.0 の「一覧から消えたら閉じる」規則) |

### Playlist ビュー

曲の並びは `playlist_musics` で固定されているため、再取得で表示が更新されるだけです。追従処理はありません。

## 実装

- 追従の判定は純関数 (`nextArtistRouteOf`、`nextAlbumKeyOf`) にしてテストを並置します
- 判定はダイアログの `apply` から行わず、各ビューが `updated` を受け取れるよう `musicInfoStore` に「適用完了」の通知 (`onApplied` 購読) を持たせます。ビュー側のフックがこれを購読して自分の状態を更新します
