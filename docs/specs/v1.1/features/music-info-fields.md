# 編集項目と validation

曲情報ダイアログの Details タブで編集できる項目と制約です。すべて `musics` テーブルの既存列に対応し、スキーマ変更はありません。

## 項目一覧

フォーム上の値はすべて文字列 (複数選択のミックスは `null`) とし、保存値への変換は適用時に純関数 `toMusicTagPatch` で行います。

| 項目 | フォーム値 | 制約 | 保存値 (`MusicTagPatch`) |
| --- | --- | --- | --- |
| title | 文字列 | 単曲では必須 (trim 後に空なら「必須」エラー) | そのまま |
| artist / albumArtist / album / genre | 文字列 | なし | trim した値。空文字はタグ削除 |
| composer / lyricist / producer / conductor / publisher | 文字列 | なし | 〃 |
| year | 数字文字列 | 空、または 1〜9999 の整数 | 空は `null` (タグ削除)、それ以外は整数 |
| track | 数字文字列 | 空、または 0 以上の整数 | 空は `0` (DB の既定値) |
| disc | 数字文字列 | 空、または 1 以上の整数 | 空は `1` (DB の既定値) |
| bpm | 数字文字列 | 空、または 1 以上の整数 | 空は `null`、それ以外は整数 |
| rating | 数字文字列 | 空、または 0〜5 の 0.5 刻み | 空は `null`、それ以外は `値 / 5` (mme の正規化値 [0, 1]) |

- rating の表示は `DB 値 × 5` です。v1.0 の読み取り専用表示は正規化値をそのまま出していましたが、ユーザーが扱う単位に合わせて 5 段階にします。星 UI は v1.x で検討します
- 複数選択で title を編集した場合、すべての曲に同じタイトルが書き込まれます。ミックスのまま触らなければ変更されないため、v1.1 では項目ごとの例外は設けません ([複数選択の編集](multi-edit.md))
- `trackTotal` / `discTotal` はフォームにありませんが、ファイルの値は保持されます ([メタデータの書き込み](../architecture/metadata-write.md))

schema の定義とテスト方針は [曲情報の zod schema](music-info-schema.md) を参照してください。
