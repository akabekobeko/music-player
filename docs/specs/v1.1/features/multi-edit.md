# 複数選択の編集

曲リストで複数の曲を選択して「Song info」を開くと、選択した曲を合成した情報を表示し、まとめて編集できます。選択操作は [曲リストの複数選択](selection.md) を参照してください。

## 合成表示

ダイアログを開くとき、純関数 `mergeMusics(musics): MergedValues` で項目ごとに初期値を決めます。

| 状況 | 初期値 | 表示 |
| --- | --- | --- |
| すべての曲で値が一致 | その値 (文字列) | そのまま表示 |
| 一致しない曲がある | `null` (ミックス) | 空欄 + placeholder「Mixed」(i18n `musicInfo.mixed`) |

- 比較は保存値どうしで行います (`year` の `null` と `2001` は不一致、文字列は完全一致)
- 単曲のときは `mergeMusics([music])` がそのまま初期値になり、ミックスは発生しません。単曲と複数で処理を分けません
- Artwork タブは `picturePath` が一致した場合のみ表示し、不一致はプレースホルダーアイコンにします。ファイルを選ぶか Remove を押すと全曲に適用されます ([アートワークの編集](artwork-edit.md))

## ミックス状態の規則

ミックスは「未編集」を表す特別な状態で、フォーム値の `null` で表現します。

1. **未編集ならその項目は適用対象にならない**。`MusicTagPatch` に含めず、各曲の値はそのまま残る
2. **編集した時点で通常の文字列になる**。入力欄に 1 文字でも入れると値は文字列になり、placeholder は消える
3. **編集後に空欄へ戻してもミックスには戻らない**。値は空文字 `""` であり、「空欄 = タグ削除」として適用される。ミックスへ戻したい場合はダイアログを開き直す

## 変更判定

適用ボタンの活性化 ([曲情報ダイアログの編集](music-info-dialog.md)) は「初期値と現在値の比較」に一本化します。TanStack Form の `isDefaultValue` がフィールドごとに `現在値 === 既定値` を返すため、次の表がそのまま成り立ちます。

| 初期値 | 現在値 | 判定 |
| --- | --- | --- |
| `"Rock"` | `"Rock"` | 変更なし |
| `"Rock"` | `"Jazz"` | 変更あり |
| `"Rock"` | `""` | 変更あり (削除) |
| `null` (ミックス) | `null` | 変更なし (未編集) |
| `null` (ミックス) | `"Rock"` | 変更あり |
| `null` (ミックス) | `""` | 変更あり (削除。規則 3) |

- 「変更あり」の項目だけを `toMusicTagPatch` で `MusicTagPatch` へ変換し、`mp:library:updateMusics` に渡します
- `title` の必須チェックは単曲 (対象 1 件) のときだけ行います。複数選択で title がミックスのままなら適用対象外なので問題になりません

## 実装

- `mergeMusics` と「変更ありの項目を抽出する `diffFormValues`」はフォームライブラリーに依存しない純関数として `MusicInfoDialog/` 配下に置き、テストを並置します
- 入力欄は `value={field.value ?? ""}` と `placeholder={field.value === null ? t("musicInfo.mixed") : undefined}` で描画します。`onChange` は常に文字列を set します
