# 取得結果の比較と採用 (Artwork タブ)

曲情報ダイアログで取得 ([曲情報ダイアログの取得ボタン](music-info-fetch.md)) が成功し、**候補に画像がある場合だけ**、Artwork タブを左右 2 分割の比較表示に切り替えます。候補に画像がなければ v1.1 の表示のままです。

## 画面構成

```
┌ [Details] [Artwork] [File] ─────────────────────────────┐
│ ┌ 現在 ──────────────┐  ┌ MusicBrainz ────────────────┐ │
│ │  ┌──────────────┐   │  │  ┌──────────────┐           │ │
│ │  │  現在の画像    │   │  │  │  取得した画像  │           │ │
│ │  │ (なければ      │   │  │  │  (data: URL)  │           │ │
│ │  │  プレースホルダー)│   │  │  └──────────────┘           │ │
│ │  └──────────────┘   │  │           [x] こちらを採用     │ │
│ │ [Choose file…] [Remove] │  └─────────────────────────────┘ │
│ └────────────────────┘                                      │
└──────────────────────────────────────────────────────────────┘
```

- 左右とも `Stack`。左は v1.1 の `ArtworkPanel` の内容 (画像 + 選択と削除 UI) をそのまま置き、右は画像とチェックボックスです
- 現在の画像がない場合も、左の画像領域はプレースホルダーアイコン (`Music`) で埋めて左右の高さを揃えます
- 右のチェックボックスは「こちらを採用」ラベルつき (i18n `musicInfo.adoptFetched`) で、領域内で右寄せ (`HStack` + `Spacer`)
- 採用される側の画像枠を採用色にします ([採用色の選定](adopt-color.md))。チェックがオンなら右、オフなら左

## 取得した画像の扱い

- 候補の `picture` (`Uint8Array` + MIME) を Renderer で Base64 化し、`data:<mime>;base64,...` を `<img src>` に渡します。Blob URL でもよいのですが、`revokeObjectURL` の管理を増やさないため `data:` URL にします
- 画像は `useMusicInfoDialog` の state に置き、ダイアログを閉じる (= コンポーネントのアンマウント) と DOM と state から自然に消えます。ファイルには書きません
- 採用して適用した場合だけ、v1.1 のアートワーク差し替えと同じ経路 (`UpdateMusicsRequest.picture`) で保存されます ([アートワークの編集](../../v1.1/features/artwork-edit.md))
- 画像は 1,200 px のサムネイルか原寸 ([検索と照合](../architecture/lookup-strategy.md)) で、数 MB 程度です。IPC と Base64 のコストは許容します

## チェックボックスの規則

| 事象 | 「こちらを採用」 |
| --- | --- |
| 取得直後 (既定値) | 現在の画像がなければオン、あればオフ |
| 左でファイルを選択する | オフ (選んだファイルを優先) |
| 左で Remove を押す | オン (削除の代わりに取得した画像を入れる) |
| ユーザーが切り替える | その値 |
| 取得ボタンを押し直す | 破棄して既定値を再計算 |

- 「Remove でオン」は、現在の画像を消したい場面で取得した画像に置き換えるのが自然な流れだからです。取得した画像も要らなければ手でオフにすれば `pictureChange = "clear"` のまま削除されます

## 変更判定と適用

v1.1 の `pictureChange` に「候補の採用」を加えます。

| `adoptPicture` | `pictureChange` | 適用する `picture` |
| --- | --- | --- |
| オン | 問わない | 候補の `{ mimeType, data }` |
| オフ | `null` | 省略 (変更なし) |
| オフ | `{ file }` | 選んだファイル |
| オフ | `"clear"` | `null` (削除) |

- 「変更あり」は `adoptPicture || pictureChange !== null` です
- 左の表示 (`imageUrl`) は v1.1 の規則のまま、右の表示は候補の `data:` URL で固定です。採用の切り替えで左右の画像は入れ替えません (枠線色だけが変わる)
