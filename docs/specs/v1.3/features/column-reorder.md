# カラムの並べ替え

ヘッダーをドラッグ & ドロップして、カラムの並び順を変えます。music-metadata-editor の GUI (`useColumnDragAndDrop`) と同じ方式です。

## 操作

- 切り替えられるカラム ([カラム定義](columns.md)) のヘッダーの表示名をドラッグし、別のカラムのヘッダーへドロップします
- ドラッグ中のカラムのヘッダーは半透明になります
- ポインターが乗っているヘッダーの左半分なら左隣へ、右半分なら右隣へ入ります。入る位置を、対象のヘッダーの端の線で示します
- ドロップすると並び順を確定し、設定へ保存します ([カラム設定の永続化](../architecture/column-settings.md))
- 動かしても並び順が変わらない位置 (自分自身、いまの隣) では線を出さず、ドロップしても何もしません
- ヘッダーの外でドロップしたとき、Esc で取り消したときは何も変えません
- ドラッグしないクリックは、これまでどおりソートの切り替えです ([ソート](column-sort.md))

## 動かせるカラム

- 常に表示するカラム (連番、タイトル、メニュー) は動かせません。連番とタイトルは左端、メニューは右端のままです
- 常に表示するカラムのヘッダーへドロップしたときは、切り替えられるカラムの並びの端へ入ります。連番とタイトルなら先頭、メニューなら末尾です
- 末尾へ入るときの線は、最後のカラムの右端ではなくメニュー カラムの左端へ出します。メニュー カラムは右端へ固定されているため、横スクロールの途中でも線が見えます
- リサイズ ハンドルからはドラッグが始まりません。ドラッグの起点は表示名の要素で、ハンドルはその外にあるためです ([カラム幅のリサイズ](column-resize.md))

## 並び順の持ち方

並び順は `visibleIds` の配列の順序です。専用の項目は持ちません。

- 表示順は「連番、タイトル、`visibleIds` の順の切り替えられるカラム、メニュー」です (`resolveVisibleColumns`)
- 既定の並び順はカラム定義の宣言順です
- 非表示のカラムは並び順を持ちません。カラム メニューで表示したときは、宣言順でそのカラムより前にあり、表示中のカラムのうち最も近いものの右隣へ入れます。前に表示中のカラムがなければ、後ろで最も近いものの左隣へ入れます。並べ替えていない状態では宣言順のままになります ([表示カラムの切り替え](column-visibility.md))
- カラム メニューの項目は、並び順にかかわらず宣言順で並べます。メニューの項目の位置が動かないようにするためです
- 「Reset columns」は並び順も既定へ戻します。並び順だけが既定と違う場合も活性にします

## 実装

```ts
// src/renderer/pages/playlists/components/PlaylistTable/useColumnReorder/useColumnReorder.ts
type Args = {
  /** Visible columns in display order. */
  readonly columns: readonly PlaylistColumn[];
  /** Persists the move; called once when the column is dropped. */
  readonly onColumnMove: (
    columnId: PlaylistColumnId,
    targetId: PlaylistColumnId,
    side: ColumnDropSide,
  ) => void;
};
```

- ネイティブの Drag & Drop (`draggable`) を使います。行の並べ替えと同じ方式です
- ドラッグ中の状態 (動かしているカラムと入る位置) は hook の `useState` に持ちます。store と設定はドロップまで変えません
- hook は `PlaylistTableHeader` が呼びます。ドラッグ中の状態を使うのはヘッダーだけなので、状態が変わっても行は再レンダーされません
- 入る位置は純関数 `columnDropOf` で求めます。常に表示するカラムの読み替えと、並び順が変わらない位置の判定を含みます
- 並び順の計算は純関数 `reorderColumnIds` です。動かすカラムを配列から抜き、対象の前か後ろへ差し込みます。変化がなければ同じ配列を返します
- store へは reducer のアクション `moved` (`columnId` / `targetId` / `side`) で反映します
- ドラッグの起点はヘッダーのセル (`<th>`) ではなく、中の表示名の要素です (ソートできるカラムは `<button>`、できないカラムは `<span>`)。ドロップ先は各セルです
- ヘッダー以外から始まったドラッグ (行の並べ替え、外部からのファイル) は無視します。hook がドラッグの開始を持たないときは何もしません。行の側も、行のドラッグでなければ何もしません
- ユーザー操作を起点とするイベント ハンドラーだけで構成し、useEffect は使いません

## 対象外

- キーボードでの並べ替え。ポインター操作のみです (リサイズと同じ)
- 常に表示するカラムの移動
