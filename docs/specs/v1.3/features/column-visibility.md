# 表示カラムの切り替え

コンテンツ ツールバーのメニュー ボタンから、テーブルに表示するカラムを切り替えます。先行例の `ColumnsMenu` と同じ構成です。

## メニュー ボタン

- 位置はコンテンツ ツールバー (`ContentToolbar`) の右側、**曲の絞り込みテキストボックスの左隣**です
- Playlists ビュー (`sectionOf(pathname) === "playlists"`) のときだけ表示します。Artists / Albums ビューと設定画面には出しません
- プレイリストを選択していないとき (`/playlists`) も表示します。カラムの設定は全プレイリスト共通で、選択の有無で出し入れするとツールバーの配置が揺れるためです
- アイコンは lucide の `Columns3`、ボタンは `GlowIconButton` です。ツールチップとアクセシブル ネームは i18n `toolbar.columns` (en: `Columns`、ja: `カラム`)
- ツールバーの背景はウィンドウのドラッグ領域なので、ボタンには `app-region-no-drag` を付けます

```
┌ コンテンツ ツールバー ─────────────────────── [▥] [ Filter songs      ] ┐
```

## メニューの内容

ボタンを押すと `DropdownMenu` を開きます。

```
☑ Artist
☑ Album
☐ Album Artist
☐ Genre
☐ Year
...
☑ Time
──────────────
  Reset columns
```

- 切り替えられるカラムを、カラム定義の宣言順にチェックボックス項目 (`DropdownMenuCheckboxItem`) で並べます
- 項目の表示名はヘッダーと同じ i18n キーです
- **常に表示するカラム (連番、タイトル、メニュー) は項目に出しません。** 切り替えられないものを並べても操作の対象にならないためです
- チェックを切り替えてもメニューは閉じません (`closeOnClick={false}`)。続けて複数のカラムを切り替えられます
- 切り替えは即座にテーブルへ反映し、設定へ保存します ([カラム設定の永続化](../architecture/column-settings.md))

## 既定値へ戻す

区切り線の下に「Reset columns」(i18n `toolbar.resetColumns`。ja: `カラムを初期状態へ戻す`) を置きます。

- 表示するカラムと幅の両方を既定値へ戻します (`playlistColumns` を既定の `visibleIds` と空の `widths` にする)
- 既定値と同じ状態のときは非活性にします
- 確認ダイアログは出しません。失うのは表示の設定だけで、すぐに再設定できるためです

## カラムを切り替えたとき

| 状況 | 挙動 |
| --- | --- |
| カラムを表示した | 宣言順の位置へ差し込む。幅は保存値、なければ既定幅 |
| カラムを非表示にした | 幅の保存値は残す。再び表示したときに同じ幅へ戻る |
| ソート中のカラムを非表示にした | 登録順へ戻る ([ソート](column-sort.md)) |
| すべてのカラムを非表示にした | 連番、タイトル、メニューだけのテーブルになる |
| 表示するカラムが増えてコンテナーを超えた | 横スクロールする ([カラム幅のリサイズ](column-resize.md)) |

## 状態の流れ

```
カラム メニュー ──toggle(id)──▶ playlistColumnsStore ──▶ mp:settings:set
                                     │
                                     └─ subscribe ──▶ PlaylistContent (テーブル)
                                                  └─▶ カラム メニュー (チェック状態)
```

メニューとテーブルは別のコンポーネント ツリーにあるため、どちらも store を `useSyncExternalStore` で購読します。曲の絞り込み (`trackFilterStore`) と同じ構成です。
